## Что это за проект

**Прод: https://xabos161rus-pixel.github.io/ai-platform/** (GitHub Pages,
деплой автоматом из main, workflow «Deploy to GitHub Pages»).

BYOK-платформа для работы с ИИ через API: React 19 + TypeScript + Vite 8
(rolldown) + Tailwind CSS 4 (CSS-first) + Dexie 4 (IndexedDB). PWA, работает
на маке и айфоне. Сервера у приложения нет — ключи живут в IndexedDB
устройства и уходят напрямую провайдеру. Дизайн-язык — Claude Code: тёплые
нейтрали oklch, один акцент, моно-шрифт только для машинного слоя,
токены `--cc-*`.

История: Влад решил строить свою платформу вместо ChatBox и аналогов; за
основу дизайна взят Claude Code; из РФ большие провайдеры недоступны
(OpenAI/Anthropic/Google — 403, OpenRouter отрезал РФ), поэтому пресеты —
российские агрегаторы (Polza, VseGPT, BotHub) + DeepSeek напрямую (работает,
проверено Владом вживую). Демо-провайдер без сети делает всё проверяемым.

## Архитектура одним экраном

- `src/db/` — типы и Dexie: SCHEMA_VERSION=5 (v1 база, v2 personas,
  v3 snippets, v4 syncConfig, v5 индекс createdAt у messages). Правило: новая таблица = новая version(),
  прежние наследуются; неиндексируемые поля версии не требуют. В проде
  живые данные — миграции бережные, обратная совместимость чтением.
  Удаление ТОЛЬКО мягкое (deletedAt) — на нём стоит синк.
- `src/lib/ai/client.ts` — OpenAI-совместимый адаптер (/chat/completions),
  SSE-стриминг с буфером, reasoning из delta.reasoning_content ?? reasoning,
  tool_calls аккумулируются по index.
- `src/lib/ai/chatRepo.ts` — операции над чатами; дерево версий
  (Message.parentId + Chat.activeLeafId, чистые функции в tree.ts, legacy
  без parentId = линейная цепочка); сравнение моделей (runId-группа,
  победитель уходит в контекст).
- `src/lib/ai/agentLoop.ts` — агентский цикл (≤8 раундов, research 12),
  wireTail только в памяти прогона, в Dexie одно сообщение с toolTrace.
- `src/lib/ai/tools.ts` — web_search (сервер /search при включённом синке →
  молчаливый фолбэк на Jina s.jina.ai с X-Respond-With: no-content),
  read_page (r.jina.ai), get_time. Ошибки — русские самодиагностирующие
  тексты: их читает модель и пересказывает пользователю.
- `src/lib/sync/` — синхронизация: crypto.ts (фраза → PBKDF2 310k → HKDF →
  spaceId + authToken + ключ AES-GCM; фраза НЕ хранится), engine.ts (цикл
  по паттерну life-hub: полуоткрытое окно push, pull с курсором
  (updatedAt, id), LWW, атомарная критическая секция — флаг до первого
  await), config.ts (Dexie-таблица syncConfig).
- `server/` — Cloudflare Worker ai-platform-sync: D1 (spaces TOFU по хэшу
  токена + records только с шифротекстом), /sync/push (ON CONFLICT не
  перетирает более новое), /sync/pull (row values курсор), /search (прокси
  Serper, gl/hl=ru, ключ — секрет воркера, без него 501). CORS только
  прод-origin + localhost. Деплой — workflow «Деплой воркера»
  (.github/workflows/worker.yml): без секретов Cloudflare мягко
  пропускается (гейт через step output).
- `src/lib/i18n.ts` — свой словарь ru/en, TKey = keyof typeof ru, en
  типизирован Record<TKey, string> — пропущенный перевод не соберётся.
- `scripts/contrast.mjs` — проверка контраста палитры в обеих темах по
  WCAG (норма AA 4.5:1). Гонять после любой правки цветов: смоук проверяет
  поведение, а не читаемость. Палитра в oklch — браузер отдаёт переменные как
  `oklch(18.5% .004 75)`, скрипт конвертирует сам.
- `scripts/smoke.mjs` — единственная автопроверка: Playwright-сценарий,
  153 проверки, финал «SMOKE: ВСЁ ЗЕЛЁНОЕ». Синк и Anthropic проверяются
  route-моками.

## Капканы (не наступать повторно)

- Tailwind 4: размер шрифта через `text-[length:var(--cc-text-X)]` —
  голое `text-[var(...)]` компилируется как color (уже ловили на проде).
- ESLint: erasableSyntaxOnly (никаких parameter properties), сброс форм —
  key-перемонтированием (не setState в эффекте), хуки/контексты — в
  отдельных файлах (only-export-components), не писать в ref в рендере.
- `vite preview` требует явный `--base=/ai-platform/`.
- Из песочницы Claude Code Remote github.io и jina.ai НЕДОСТУПНЫ (прокси
  403) — статус деплоя проверять через GitHub Actions API; ответ
  actions_list огромный — сохранён в файл, парсить jq.
- vite.config.ts: manualChunks только функцией (rolldown); BUILD_ID через
  `<meta>` в HTML, НЕ через define (менял хэш чанка → ложные пуши
  сторожа обновлений PWA).
- Артефакты/предпросмотр кода: iframe sandbox="allow-scripts" БЕЗ
  allow-same-origin (opaque origin не видит IndexedDB с ключами).
- Демо-агент триггерится на /найди|поиск|search/i в demo-провайдере —
  smoke опирается на это.

## Проверка перед пушем (обязательный ритуал)

```
npm run lint && npm run build
(npx vite preview --port 4174 --base=/ai-platform/ &) 
node scripts/smoke.mjs   # ждать «SMOKE: ВСЁ ЗЕЛЁНОЕ»
```

После пуша в main — подтвердить деплой: последний run по main в Actions
должен быть completed/success (у репо два workflow: Pages и «Деплой
воркера»; второй без секретов зелёный-пропущенный).
