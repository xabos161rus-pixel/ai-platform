# AI Platform

Своя площадка для работы с ИИ через API. BYOK: ключи хранятся только на
устройстве и уходят напрямую провайдеру — посредников между пользователем и его
ключом нет. PWA: ставится на macOS и iPhone из Safari, без App Store и без
платы за аккаунт разработчика.

Дизайн — язык Claude Code: тёплые нейтрали, единственный акцент клай `#D97757`,
моноширинный шрифт только на машинном слое.

## Что уже работает

- Чат с моделью, список чатов, закрепление, авто-заголовок из первого вопроса
- Markdown в ответе: заголовки, списки, таблицы, блоки кода, цитаты
- Повтор ответа, копирование, остановка генерации, экспорт диалога в markdown
- Провайдеры: адрес API + ключ + список моделей, пресеты популярных агрегаторов
- Встроенная заглушка — платформа отвечает сразу после установки, без ключа
- Счётчик токенов и стоимости под каждым ответом, расход за месяц в настройках
- Ограничение контекста: сколько последних сообщений уходит в модель
- Тёмная/светлая/системная тема

## Архитектура

- **React 19 + TypeScript + Vite 8**, Tailwind CSS 4 (CSS-first, токены в `src/index.css`)
- **Dexie.js (IndexedDB)** — чаты, сообщения, провайдеры, настройки; `useLiveQuery` как слой состояния
- **PWA** через vite-plugin-pwa, `autoUpdate` — новая версия подтягивается молча
- **Бэкенда нет.** Браузер обращается к API провайдера напрямую
- Хостинг: GitHub Pages, base path `/ai-platform/`

### Провайдеры

Все поддерживаемые API — OpenAI-совместимые (`POST /chat/completions`), поэтому
один адаптер закрывает и российские агрегаторы, и зарубежные сервисы, и
локальный сервер: различаются только `baseUrl` и ключ. Anthropic со своим
форматом Messages добавится отдельным адаптером, когда понадобится.

Ключ лежит в IndexedDB устройства. Это осознанный размен: платформа BYOK, и
ключ не должен проходить через чужой сервер — включая наш собственный.

**Известное ограничение:** браузерный запрос к зарубежному API из России
упирается и в CORS, и в геоблокировку по региону (403). Российские агрегаторы
(Polza.ai, VseGPT, BotHub) этой проблемы не имеют — они и стоят первыми в
пресетах. Прокси на Cloudflare Worker как обход добавим, если понадобится
ходить к зарубежному провайдеру напрямую.

### Слой данных

Каждая запись наследует `BaseEntity` (`id` uuid, `createdAt`, `updatedAt`,
`deletedAt` — мягкое удаление). Синхронизации между устройствами пока нет:
чат живёт на том устройстве, где начат, страховка — экспорт в markdown.

### Стоимость

Считается на клиенте из `usage`, который вернул провайдер, и прайса из
`src/lib/ai/models.ts` (в рублях за миллион токенов). Снимок стоимости пишется
в сообщение: прайс со временем меняется, а «сколько это стоило» — факт.

Предварительная оценка по символам показывается только со знаком «≈» и на неё
не завязаны лимиты: русский текст токенизируется заметно дороже английского,
поэтому такая оценка систематически занижена.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173/
npm run build    # tsc + vite build + service worker
npm run lint
npm run smoke    # сквозной сценарий в браузере
```

`npm run smoke` — единственная автоматическая проверка в проекте (Playwright +
Chromium, `scripts/smoke.mjs`): открытие чата, вопрос → ответ → метрики,
markdown, авто-заголовок, история после перезагрузки, настройки, темы, форма
провайдера, второй чат. Гонять перед каждым коммитом.

Preview поднимается с `--base=/ai-platform/` намеренно: `base` в конфиге
зависит от команды, а `vite preview` — это `serve`, и без флага она отдаёт
ассеты не по тому пути, страница остаётся пустой.

Иконки генерируются из разметки — `node scripts/make-icons.mjs` рендерит SVG
браузером и снимает PNG нужных размеров. Значок правится как код.

## Деплой

Push в `main` → GitHub Actions прогоняет линт, собирает и публикует на GitHub
Pages. `dist/index.html` копируется в `404.html`: без этого прямой заход по
`/settings` вернул бы 404 от сервера, до роутера дело бы не дошло.

После первого деплоя включить Pages: Settings → Pages → Source: **GitHub
Actions**. Адрес будет `https://xabos161rus-pixel.github.io/ai-platform/`.
