## Ритуал перед каждым пушем (обязателен)

```
npm run lint && npm run build
(npx vite preview --port 4174 --base=/ai-platform/ &)   # --base обязателен
node scripts/smoke.mjs      # ждать «SMOKE: ВСЁ ЗЕЛЁНОЕ», сейчас 134 проверки
```

Смоук — единственная автопроверка проекта, юнит-тестов нет. На новой машине
нужен `npx playwright install chromium`. Путь `/opt/pw-browsers/chromium`
берётся, только если существует (облачная песочница).

## Что построено за эту сессию

1. **Токены и деньги.** Живой месячный бюджет (полоса, предупреждение на 80%,
   блокировка отправки на 100%, демо не гейтится); счётчик «≈ N токенов · цена»
   ВНУТРИ капсулы композера; учёт reasoning- и cache-токенов; схема Dexie v5 —
   индекс `createdAt` у messages (range вместо полного скана).
2. **Консилиум моделей** (`src/lib/ai/council.ts`, `CouncilGroup.tsx`,
   дизайн — `docs/COUNCIL-DESIGN.md`): мнения → дебаты с анонимизацией
   («Ответ A/B/C», перемешано) → взаимное ранжирование JSON → председатель
   сводит финал. Стадии пишутся в Dexie по готовности одной runId-группой,
   финал `chosen` и уходит в контекст. Оборванный прогон виден блоком.
   Демо-стадии отвечают мгновенно (`demoInstant`), чтобы смоук не стоял минуты.
3. **Сплит-вью**: `ChatPage` распилен на оркестратор (сайдбар, палитра,
   глобальные хоткеи) и `ChatPane` (вся жизнь одного чата). «Открыть рядом» в
   меню чата, вторая панель ≥xl, пара переживает перезагрузку.
4. **Дизайн**: свой набор из 42 глифов (`components/ui/glyphs.tsx`, lucide
   удалён из зависимостей); капсула композера с контролами внутри; режимы
   «сравнение» и «консилиум» — отдельные иконки в капсуле; sentence-case
   лейблы вместо капсов; акцентный focus-visible вместо синего UA-outline
   (внутри `.cc-capsule` кольца элементов сняты — была рамка в рамке);
   тихая структура настроек; шиты центрируются на десктопе; клай-выделение
   текста; заголовок вкладки по активному чату.
5. **Демо убран из глаз**: при живом провайдере демо-моделей нет ни в пикере,
   ни в чипах, ни в регенерации, ни в настройках. Возврат автоматический —
   удаление последнего живого провайдера возвращает актив на демо.
6. **Папки и подпапки** чатов: путь «Родитель/Дитя» в поле `chat.folder`
   (ноль миграций), глубина 2 уровня; кнопка «Новая папка» в сайдбаре;
   пустые папки живут в `settings.customFolders`, удаляются корзинкой.
7. **Статистика** — страница `/stats` (ленивый чанк, вход внизу сайдбара):
   сводка сегодня/месяц/всего, **«Потрачено по моделям · всё время» с барами
   долей** (главный блок по просьбе Влада), градусник 30 дней, разбивки по
   моделям/чатам/месяцам. В настройках остался только контроль бюджета.
8. **Поиск с цитатами**: `web_search` нумерует результаты сквозно по прогону,
   реестр источников живёт в замыкании `buildTools`; в ответе `[n]` —
   кликабельная сноска, под ответом блок «Источники» (номер, заголовок, домен).
   Блок строится ИЗ ДАННЫХ, не из текста модели — выдуманных ссылок быть не может.
9. **Автоподтягивание моделей**: кнопка «Подтянуть список» в редакторе
   провайдера — `GET /models`, новые id строками, введённые цены не трогаются.

## Грабли этой сессии (не повторять)

- **Не перезаписывать существующие файлы целиком по памяти.** Так я снёс
  сегментный рендер `Markdown.tsx` вместе с веткой `CodeBlock` (подсветка и
  предпросмотр артефактов). Поймал смоук, восстановил из git. Правки — точечные.
- Playwright-локаторы по видимому тексту скачут, когда текст дублируется
  (модели в чипах и в пикере шапки) — у чипов есть `data-testid="compare-chip:…"`.
- Смоук живёт на демо-провайдере; после сцен, меняющих активного провайдера,
  демо возвращается помощником `activateDemo()` (прямая запись в IndexedDB,
  UI-строки демо больше нет).
- `vite preview` без `--base=/ai-platform/` отдаёт ассеты не по тому пути.
- Tailwind 4: размер шрифта только `text-[length:var(--cc-text-X)]`.
