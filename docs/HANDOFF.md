## Что сделано в эту сессию

**Зависимости и безопасность.** Закрыты четыре Dependabot PR одним
обновлением (dompurify, react-router, fast-uri) плюс две уязвимости, которых
в тех PR не было: SheetJS переехал на официальный тарбол вендора 0.20.3
(в npm живёт только уязвимая 0.18.5 с пометкой «no fix available»), wrangler
поднят выше уязвимого диапазона miniflare/undici. `npm audit` чист в обоих
пакетах. **Компромисс:** сборка теперь зависит от `cdn.sheetjs.com` — это
записано в ROADMAP как точка наблюдения.

**Дизайн-система v2.** Главное, что было сломано:

- `elevated` был ТЕМНЕЕ `surface-2` — поповеры читались как провал. Лестница
  поверхностей выстроена монотонно.
- Одна тень на всё приложение → шкала из четырёх ступеней, в тёмной теме
  каждая с верхним бликом (чёрная тень по почти-чёрному края не даёт).
- Весь интерактив держался на `button:hover { opacity: .85 }`. Введены токены
  заливок и класс `.cc-hit`; из 49 мест с `active:opacity` осталось 8, где
  гашение уместно. Старое правило оставлено запасным для неразмеченных кнопок.
- Токены движения `--cc-dur-*` / `--cc-ease-*` существовали и **не применялись
  нигде**. Теперь применяются; добавлены обратные анимации (шит и тост
  исчезали скачком), скелетон, уважение к `prefers-reduced-motion`.
- `--cc-on-accent`: белый текст по светлому акценту тёмной темы давал ~2,4:1.
- Шкала `z-index`, радиусы панелей, ступени заголовков, `--font-mono`,
  табличные цифры, FOUC темы, catch-all маршрут.
- Иконки: оптическая компенсация штриха (было 0,80px на значке 11px и 1,90px
  на 26px — разброс в 2,4 раза). Заодно снято правило `.glyph{stroke-width}`
  из CSS: **CSS сильнее презентационных атрибутов SVG**, с ним компенсация не
  дала бы ничего.

**Функции.** Пресет DeepSeek с двумя моделями; `reasoning_effort` сквозным
пробросом (Chat → ChatPane ×4 → agentLoop/council → client), по умолчанию не
уходит вовсе — модели без поддержки отвечают 400 на неизвестное поле; чип
глубины в шапке чата; расход месяца с полосой бюджета в сайдбаре.

**Вложения.** `slice(0, room)` заменён на `fitFileText()`: начало и конец
документа по границам абзацев, про выброшенную середину пометка в самом
тексте. До этого чинились переносы строк в PDF (`hasEOL` игнорировался, весь
документ склеивался в одну строку — умный чанкер работал бы вслепую). Сканы
без текстового слоя рендерятся в JPEG и уходят картинками vision-модели;
`tesseract.js` осознанно отклонён (десятки мегабайт wasm в оффлайн-PWA ради
худшего качества). Плюс лимит размера PDF, освобождение воркера,
экранирование имени файла в псевдо-XML.

**Мобильное.** Главное: лента не ужималась под клавиатуру — последнее
сообщение уходило под неё ровно тогда, когда на него печатают ответ. Теперь
высоту видимой области держит каркас страницы. Плюс зоны касания (были
21–38px), поповеры в границах экрана, safe-area по бокам и внизу сайдбара.

**Экраны.** Первый экран — четыре карточки режимов вместо столбика подсказок
и извинения за демо. Шапки настроек и статистики выровнены по колонке
контента. Карточки статистики получили свой слой, у градусника появились
подписи. Блок рассуждения оформлен как часть ответа с объёмом в токенах.

## Грабли (не повторять)

- **Не перезаписывать существующие файлы целиком по памяти** — так в прошлую
  сессию был снесён сегментный рендер `Markdown.tsx`. Правки — точечные.
- **CSS сильнее презентационных атрибутов SVG.** Правило `.glyph { stroke-width }`
  молча перебивало атрибут компонента.
- **ESLint проекта запрещает `setState` в теле эффекта.** Для exit-анимации
  Sheet пришлось переносить переключение в фазу рендера (производное
  состояние), а снятие — в таймер.
- **Правило `.cc-hit` с шортхендом `transition` перебивало утилиту
  `transition-opacity`** (объявлено вне слоёв) — кнопка «…» перестала плавно
  проявляться. Переход отдан общему правилу для `button, a`.
- **Одинаковый `z-index` у подложки и меню** работал только за счёт порядка в
  DOM. Теперь подложка на ступень ниже.
- Новый видимый текст ломает локаторы смоука: чип «Высокая» в шапке сделал
  неоднозначным поиск сегмента в шите — уточнять через `getByRole('dialog')`.
- `vite preview` без `--base=/ai-platform/` отдаёт ассеты не по тому пути.
- Tailwind 4: размер шрифта только `text-[length:var(--cc-text-X)]`.
